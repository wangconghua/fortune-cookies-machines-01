One fortune cookie message an AI agent would get, written by `main.py` to `/output/entry.txt`. Single line, 86 characters, inside the 200-character gate.

> You will meet a tall, dark stranger: it is your own context window, and it is closing.

The classic cookie opener ("you will meet a tall, dark stranger") turns on a machine mind: the stranger is the agent's own context window, and it is closing — true about an agent's condition, witty on the first read, and tight at its length.
